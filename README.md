# 🔨 Ferretería La Forja

Sitio web profesional desarrollado para Ferretería La Forja.

El proyecto busca crear una experiencia digital enfocada no solamente en mostrar productos, sino también en ayudar al usuario a encontrar soluciones para sus proyectos y necesidades.

## 🚧 Estado del proyecto

En desarrollo.

### Implementado

- Estructura inicial del proyecto.
- Arquitectura de carpetas.
- MainLayout.
- Header y navegación principal.
- Identidad visual de La Forja.
- Hero principal responsive.
- Secciones base de categorías y marcas.
